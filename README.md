# Observatory-Frontend

This repository contains Observatory-Frontend.

## Requirements

To properly install and start the template, the following tools should be installed:

- Git
- Npm
![img.png](img.png)
## Installation

To properly install the template, follow these steps:

```bash
$ git clone <URL>
$ cd frontend
$ npm install
```


## Run the app locally

```bash
$ cd observatory-frontend
$ npm start
```

### Docker-compose

The provided **docker-compose.yml** build and deploy the application.

Run the following command to use the docker-compose:

```bash
$ cd observatory-frontend
$ docker-compose -f docker-compose.yml up -d 
```
